实现客户负责人、未成案客户可见性、客户详情中的沟通与跟进、结果／取消原因、下一项跟进、幂等提交、事务审计和合并迁移。提供事实来源、分批实施计划和云开发运行器。

权限继续在服务端执行。客户可见不自动扩大该客户关联案件、附件或财务权限。沟通正文没有继承财务岗位对客户主档的全所读取豁免。系统管理员身份与业务授权分开。

### 10 项真实数据库场景

1. 无案件客户对负责人可见，其他律师不能读取或写入。
2. 同键并发只保存一份沟通、下一项和审计；同键不同内容被拒。
3. 两个请求并发完成一项跟进，仅一个成功且只生成一份结果和下一项。
4. 真正的审计 SQL 写入失败时，完成状态、结果和下一项全部回滚。
5. 跨客户跟进 ID 被拒；取消保存原因与状态。
6. 业务管理读取权、系统管理员身份、财务主档范围不会自动扩大沟通写入范围。
7. CUSTOM OWN 能维护自己的未成案客户，撤销写权限后旧会话被拒。
8. 停用操作先取得授权锁时，等待中的旧岗位请求被拒。
9. 已软删除客户拒绝新增沟通，包括合伙人请求。
10. 合并迁移沟通及跟进，保留来源关联；跨负责人合并被拒。

审计的禁止删除守卫保持启用。测试结束后仅停用合成账号、软删除合成客户；测试证据保留在独立验收库。

### HTTP 和组件检查的准确含义

`tools/cloud-dev/smoke.mjs` 通过真实登录端点获得会话，读取受保护的客户列表和详情。它直接调用业务服务创建沟通、完成跟进及生成下一项，再请求服务端页面确认内容可见；另一律师和未登录请求不能取得这些客户内容。它还验证内置模板的解密和文件校验值，复用验收环境时继续使用同一专用密钥。

组件测试验证填写跟进结果、选择下次事项、上海时间转换、成功关闭弹窗、失败保留输入和无读取权限时隐藏记录入口。日期单测包含上海午夜与无效日期。

这些检查不等于真实浏览器中的完整点击、网络表单提交和视觉验收。
