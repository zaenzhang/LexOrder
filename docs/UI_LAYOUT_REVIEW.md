# 律迹逐页信息层级与布局验收

2026-11-18，主工作树 main。按用户在页面上要先完成的任务逐页审查。首要信息应进入标题、首屏或主操作。概览帮助判断状态与下一步，详情在对应区块、页签或弹层按需进入。

## 业务界面

| 界面 | 首要信息与操作 | 概览 | 次级信息和归属 |
| --- | --- | --- | --- |
| 登录 `/login` | 邮箱、密码、登录、出错后的处理 | 产品识别 | 品牌标语置左，窄屏优先表单。双步验证码按需展开 |
| 工作台 `/` | 今日风险、待我处理、近期日程 | 待办数量与近期截止时间 | 财务趋势、案件及客户分布放在行动区下方 |
| 案件列表 `/matters` | 案名、状态、搜索筛选、打开案件 | 页签数量、主办和临期期限 | 金额、程序和案号按列查看。宽表在表格内滚动 |
| 收案入口 `/intakes` | 待收案记录及入口 | 当前状态和数量 | 跳转案件列表的收案分区。历史进详情 |
| 案件详情 `/matters/[id]` | 案名、案件状态、记录办案进展、编辑和导出 | 当事人、到期风险、下一步 | 档案与摘要、办案与材料、委托与财务、审批用印逐页签承载。案件状态及共用操作已移到页头右区 |
| 收案详情 `/intakes/[id]` | 当前审核状态、核对与补正入口 | 主办责任、最近一轮送审 | 往轮送审记录、当事人及冲突核查证据按区块阅读 |
| 审批 `/approvals` | 待审事项、当前步骤、打开或发起申请 | 待我审批、已处理、我的申请和全部记录 | 具体依据和审批操作进入详情 |
| 用章入口 `/approvals/seals`、`/seals` | 当前待办和用印入口 | 同审批工作台 | 两条路径进入审批工作台，详情在对应申请中 |

| 事项责任 `/schedule?section=responsibilities` | 待接手任务、负责人、交接和改期 | 当前范围及事项状态 | 已办结和取消事项按需显示。页面仅读取责任板 |
| 客户列表 `/clients` | 客户名称、类型、筛选及查看 | 合作状态、案件与收案数量 | 证件、电话与联系人在授权范围内作为辅助信息 |
| 客户详情 `/clients/[id]` | 客户身份和下一次跟进 | 待跟进数量、联系信息 | 沟通跟进、关联案件、客户动态、客户资料四个页签 |

| 收款分配 `/finance/reconciliation` | 案件、应收余额、入账分配状态 | 当前案件余额和待处理笔数 | 分配明细、冲正和历史在对应分区 |
| 归档 `/archive` | 检索案卷、当前可用状态、借阅 | 归档号与借阅状态 | 借阅理由及审批进入共享弹窗和审批详情 |

| 冲突预检 `/conflicts` | 查询对象、风险结论、命中来源 | 各风险级别数量 | 逐条核对当事人和案件详情 |

| 财产保全 `/preservation` | 到期风险、续封和执行关联 | 当前状态和临近到期数量 | 资产明细、担保、操作记录按单件进入 |

## 浏览器检查与发现

- 3001 在桌面及 768px 两种宽度逐页访问 43 个既有页面入口，另外检查新增「事项责任与交接」分区。记录重定向并核对可访问的合成案件、收案和客户详情。
- 切换了案件列表 5 个状态、审批 4 个范围、案件详情 4 个工作区、客户详情 4 个工作区、AI 设置 5 个页签、财务 4 个工作区、日历周月列表及独立责任分区。各项操作均使用预览账号。
- 窄屏首次读布局时，案件和收案表曾测到瞬时文档溢出。等待页面完成渲染后复查，文档宽度为 768px，表格在内部滚动。保全页首次测量遇到页面切换未完成，重查正常。
- 实点案件页头编辑、取消回焦和记录入口。添加程序验证省市联动、输入与选择框默认尺寸、日期回填及 Escape 只关闭日期面板。草稿取消需要确认。以上没有提交业务变更。
- 报表查看权限和部分空数据状态限制了可见布局。未执行财务登记、审批提交或其他写入。
- 类型检查通过，17 个定向测试文件共 134 项通过。额外运行案件工作流导航时有 10 项失败，涉及环节范围、上传入口和责任板事件的预期。当前工作树同时存在这组流程的改动，暂不能把它计入通过。
